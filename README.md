# Repositório de Processos da DGEST

Repositório para publicação e consulta dos processos mapeados e documentados pela DGEST.

## Estrutura

- `index.html`: catálogo dos processos publicados;
- `processos/`: exportações estáticas dos processos;
- `.nojekyll`: impede tratamento indevido das pastas pelo Jekyll do GitHub Pages.

## Publicação

O GitHub Pages deve ser configurado para publicar a branch `main`, a partir da pasta raiz (`/`).
